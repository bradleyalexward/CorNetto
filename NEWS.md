# CorNetto 1.0

## Dense multi-assay analysis

* `testDifferentialCorrelation()` now treats `assayName = NULL` as dense
  testing across every assay. Feature pairs are generated separately within
  each assay and then combined, so no cross-omic pairs are introduced.

* `permuteRewiringScores()` inherits the same behavior: when both `assayName`
  and `candidateEdgeTable` are `NULL`, the observed analysis covers dense
  within-omic pairs from every assay, and permutations reuse the selected
  observed edge universe without introducing cross-omic pairs.

## Permutation performance

* `permuteRewiringScores()` now accepts a BiocParallel backend through
  `BPPARAM`. Serial execution remains the default; `SnowParam` can be used for
  parallel execution on Windows.

* Label permutations are generated under the existing `seed` before scoring is
  dispatched. The same seed therefore gives the same label allocations and
  numerical results across supported backend and worker-count choices.

* The new `verbose` and `progressEvery` arguments report completed
  permutations at a user-controlled interval. Parallel work is synchronized at
  the same interval, and interrupted calls cannot yet be resumed.

  # CorNetto 0.99.4

## Statistical interface

* `permuteRewiringScores()` now returns `permutationTailProbability` and
  `adjustedPermutationTailProbability` instead of p-value-labelled columns.
  This is a breaking output-schema change. The new `inferenceStatus` field is
  `"randomization p-value"` only for a prespecified, filter-free candidate
  universe whose full edge set and selected node score are estimable under
  label permutation. Other results are marked `"conditional ranking"`.

* A filter-free candidate universe is fixed before the observed analysis.
  CorNetto checks label-independent endpoint availability, missingness and tie
  patterns, then verifies that the full edge set was scored in the observed run
  and every sampled permutation.

## Data and input handling

* Third-party prior-network extracts were removed from `inst/extdata`. The
  COVID vignette now uses deterministic synthetic networks generated by
  `inst/scripts/make-synthetic-priors.R`. The example edges are arbitrary and
  are not presented as biological evidence.

* Candidate self-loops are dropped with a warning before differential
  correlation testing. Self-loops in a constructed rewiring network remain an
  error.

* `plotRewiringScores()` orders permutation tail probabilities increasingly,
  so the most extreme nodes are selected first. Existing rewiring-score columns
  retain their decreasing order.

# CorNetto 0.99.3

## Statistical corrections

* Differential-correlation p-values are now adjusted over the complete tested
  edge family before any correlation-strength filter is applied. The former
  order performed multiple-testing correction after data-dependent selection
  and could produce anti-conservative adjusted p-values.

* All-pairs differential correlation now uses pairwise-complete sample counts
  in the Fisher variance, rather than reporting and testing with the nominal
  group size when values are missing.

* Pearson tests now return an infinite test statistic and p-value zero for an
  exactly perfect sample correlation. The former numerical floor returned a
  finite statistic that did not match `stats::cor.test()`.

* All-pairs and prior-guided differential tests now share the same Fisher
  transformation, group-2-minus-group-1 orientation, and symmetric correlation
  bound near one. The unavailable `DGCA` dependency was removed.

## Input and interface corrections

* Base `data.frame` edge tables are no longer split into individual columns
  while combining networks, and factor-valued numeric or logical columns are
  interpreted from their displayed values rather than their internal codes.

* Non-finite abundance values, non-real complex matrices, duplicate assay
  names, automatic sample row names, and blank knowledge-network endpoints now
  fail with specific errors. Candidate self-loops are omitted with a warning;
  rewiring-score inputs still reject self-loops and duplicate or mirrored
  edges because those rows would change degree and score values.

* Assay names and feature identifiers containing the reserved `::` node-key
  separator are rejected, preventing distinct nodes from collapsing to the
  same graph key.

* `validateAnalysisData()` preserves alternative assays, `rowRanges`, and
  sample metadata in supplied `SummarizedExperiment` objects.

* Sample or feature filtering invalidates stored analysis results, which could
  otherwise be returned after their underlying data had changed.

* The packaged COVID metadata is restricted to the three fields used in the
  vignette (`Visit_ID`, `Group`, and `Visit`), and the shipped sample labels are
  replaced by package-local `COVID001` to `COVID024` identifiers.

## Documentation and tests

* Statistical documentation now states the Fisher test, pairwise-deletion
  policy, asymptotic rank-correlation tests, permutation assumptions, and the
  conditional interpretation required after label-dependent edge selection.

* Reference tests cover perfect Pearson correlation, pairwise sample counts,
  full-family p-value adjustment, factor coercion, invalid numeric values, and
  duplicate-edge handling.

# CorNetto 0.99.2

## Bug fixes

* `permuteRewiringScores()` no longer pads the null distribution with zeros for
  nodes that are absent from a permuted network. A node that is not scored in a
  permutation is now recorded as missing rather than as a node with zero
  rewiring. Because the rewiring score is a norm and cannot be negative, the old
  padding meant those permutations could never count as extreme, which biased
  empirical p-values downwards. The new `contributingPermutations` column
  reports how many permutations produced a score for each node.

* `permuteRewiringScores()` now attempts to score the observed edge set in every
  permutation instead of rebuilding and refiltering the network each time.
  Edges can still be unestimable when pairwise data are insufficient or a
  feature is constant; `contributingPermutations` makes that loss visible.

* `createCorrelationNetwork()` no longer emits rows of all-missing values.
  Feature pairs with fewer than three shared observations have no p-value, and
  the resulting `NA` in the filtering index caused `NA` rows to be added to the
  edge table.

* `createDifferentialCorrelationNetwork()` no longer fails with "missing value
  where TRUE/FALSE needed" when a feature is constant within one group. Such
  edges now receive `edgeDirection = NA`.

* `SummarizedExperiment` inputs holding more than one assay matrix are rejected
  instead of silently using the first one. Name the intended matrix `abundance`,
  or subset the object before calling `createAnalysisData()`.

* `createNetworkGraph()` and `createFocusedNetwork()` now add a reverse copy of
  each undirected edge when the graph is directed, so undirected edges are
  traversed symmetrically under `mode = "in"` and `mode = "out"`.

* Missing `edgeDirection` and `edgeType` values in a knowledge network now fall
  back to the supplied defaults before edge direction is inferred, instead of
  being read as directed.

* `groupLevels` must now contain two distinct, non-missing labels.

* `sampleIds` values that are not present in the object are now an error rather
  than being silently dropped, matching `filterSamples()`.

* `filterFeatures()` handles features whose variance is `NA` explicitly in the
  `minimumVariance` filter.

* `plotRewiringScores()` no longer plots blank bars when fewer than `topN`
  nodes have a score.

## Significant user-visible changes

* `calculateRewiringScores()` returns `NA` for `degreeMatchedZScore` in degree
  bins holding fewer than five nodes, or no spread. A two-node bin previously
  returned +/-0.707 regardless of the data, and a one-node bin returned 0, which
  read as "average" rather than "not estimable".

* `calculateRewiringScores()` warns when the network contains undirected edges
  together with their reverse copies, which would count every edge twice.

* `writeNetworkTables()` requires `directoryPath`; it no longer defaults to the
  working directory.

* `createNetworkGraph()` gains `mirrorUndirectedEdges`.

* The synthetic example data now has 10 samples per group rather than 4. The
  Fisher z variance term is `1/(n1 - 3) + 1/(n2 - 3)`, so the previous examples
  ran at a standard error of `sqrt(2)`.

* `zScoreDifference` is now documented as subtracting group 1 from group 2: a
  positive value means the pair is more strongly correlated in the second of
  the supplied `groupLevels`. This runs opposite to
  the `edgeDirection` labels, which are named from group 1's point of view, so
  a `gainInGroup1` edge carries a negative `edgeWeight` under
  `edgeWeightMethod = "signedZScore"`. No computed value changed; the
  convention was simply never written down.

* `qvalue` moved from `Imports` to `Suggests`; it is only needed for
  `pAdjustMethod = "qvalue"` and was already guarded.

* Documentation now states the assumptions behind each analytical function, the
  package's missing-data policy, and the conditions under which the permutation
  null is valid. Method references carry DOIs.

* The package logo and a workflow diagram are included; the diagram opens the
  main vignette.

# CorNetto 0.99.1

## New features

* Added `summarizeKnowledgeNetwork()` for prior-network diagnostics.

## Significant user-visible changes

* Simplified the public network API: `combineNetworks()` now handles network
  integration, `getCorNettoResult()` is the main result accessor,
  `correlationResults()` replaces correlation-network-specific accessors, and
  `permuteRewiringScores()` replaces `permuteDifferentialRewiring()`.

* Removed `readAssayData()`, `mapFeatureIdentifiers()`,
  `validateSparseCorrelationEdges()`, `createCorrelationNetworks()`,
  `combineCorrelationNetworks()`, and `createIntegratedNetwork()`.

* Replaced the full COVID-19 demonstration matrices with a small reproducible
  example subset suitable for Bioconductor package checks.

* Updated the differential-correlation to rewiring workflow so
  `testDifferentialCorrelation()` first applies the absolute-correlation
  prefilter, adjusts p-values on the retained edge universe, and keeps edges
  only when the same group is both sufficiently correlated and significant.
  `createDifferentialCorrelationNetwork()` no longer applies a
  differential-correlation p-value filter by default and now uses signed
  z-score differences as the default edge weights.

## Bug fixes

* Fixed storage of named results in `MultiAssayExperiment` metadata.

# CorNetto 0.99.0

## New features

* Initial Bioconductor-oriented package scaffold.

* Added support for normalized multi-omic inputs through
  `MultiAssayExperiment`.

* Implemented knowledge-network validation, dense correlation workflows,
  prior-guided differential correlation testing, rewiring scores, pathway
  subnetworks, graph creation, and Cytoscape-ready export.

* Added synthetic example assets, tests, and an introductory vignette.

* Added permutation validation for node-level rewiring scores.

## Significant user-visible changes

* Removed `createSparseMultiOmicCorrelations()`. Prior-guided sparse
  differential correlation is now performed with
  `testDifferentialCorrelation(candidateEdgeTable = ...)`.

* Adjusted differential-correlation p-values across the full tested edge
  universe before applying significance filters. This behavior was changed in
  version 0.99.1 for the rewiring-first workflow.
